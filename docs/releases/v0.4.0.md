# GameBooster v0.4.0 — Public pre-release

This is a public preview build for testing, not a Play Store or production-signed release.

## What’s new

- Reworked the app around a branded dark gaming dashboard and four-section bottom navigation.
- Added a prominent connection control with explicit ready, switching, setup-needed, and active-tunnel states.
- Surfaced measured route latency, jitter, packet-loss estimates, session traffic, and adaptive-route details in clearer cards.
- Added a gateway-readiness state and prevent-start behavior when no game or live server is configured, rather than suggesting placeholder regions are available.
- Improved the sign-in, game-list empty state, and session-history overview.
- Included route failover resilience, session-history reload/serialization, overlay-permission refresh, and verified Supabase email-auth callback handling.

## Validation

- Android unit tests and debug APK assembly must pass in GitHub Actions for the release candidate before publishing.
- The release asset is the versioned debug APK produced by that workflow.

## Known limitations and safe use

- This is a debug/test APK, not a Play Store build or production-signed package.
- No physical-device end-to-end VPN test, live gateway deployment, or production server availability has been verified for this release.
- Only use authorized GameBooster gateways. A tunnel cannot be established until an enabled server and its authorized gateway are properly configured and healthy.
- The displayed latency is a TCP-connect measurement, not the game’s in-game UDP ping; lower in-game latency is not guaranteed.
- Smart switching may briefly interrupt a tunnel, and some games or anti-cheat policies may restrict overlays.
