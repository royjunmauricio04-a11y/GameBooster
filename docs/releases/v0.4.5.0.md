# GameBooster v0.4.5.0

## Release type

Public debug/test pre-release for Android.

## Changes

- Bumped Android `versionName` to `0.4.5.0`.
- Set Android `versionCode` to `40500`.
- Includes the merged Phase 2 lifecycle-gate increment, which cancels in-flight connection work before disconnect/reconnect and serializes high-level tunnel transitions.
- Includes the existing WireGuard engine, network callback cleanup, foreground-service failure handling, server failover, diagnostics, history, and overlay work.

## Validation

- Android GitHub Actions compile, JVM tests, and debug APK assembly must pass for the tagged commit.
- Gateway regression suite: 22 tests passed before this release-only version bump.

## Limitations

This is not a production-signed Play Store build. Physical-device Wi-Fi/mobile handoff, Android process-death recovery, DNS/IPv6 leak behavior, live gateway deployment, and production signing remain separate validation items.
